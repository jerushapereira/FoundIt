PROTOTYPE INFORMATION

Privacy

This page describes the current standalone FoundIt frontend prototype. It is not a privacy policy for a deployed campus service.

Information you enter

When you add a demo entry, the item name, location, type, and a generated demo ID are held in JavaScript memory in the open page. The prototype does not send this information to a server, save it to a database, or store it in browser storage.

How long entries remain

Entries, including the demonstration examples, are lost when the page is refreshed or closed. The prototype has no account, analytics, or contact form functionality.

Using the C program

This website does not communicate with or share data with the FoundIt C program. Any integration would require a separately designed connection and review of the data it handles.

Contact

This classroom prototype has no support or privacy contact channel. Before using it to collect real campus reports, replace this notice with information for the responsible institution and its actual data practices.
